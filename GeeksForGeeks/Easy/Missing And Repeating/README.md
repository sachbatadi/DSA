Given an unsorted array arr[] of size $n$, containing elements from the range $1$ to $n$, it is known that one number in this range is missing, and another number occurs twice in the array. Your task is to find both the duplicate number and the missing number.Expected Output Format: Return a vector/list containing two elements: [repeating, missing].Examples:Input: arr[] = [2, 2]Output: [2, 1]Explanation: The repeating number is 2 and the missing number is 1.Input: arr[] = [1, 3, 3]Output: [3, 2]Explanation: The repeating number is 3 and the missing number is 2.Input: arr[] = [4, 3, 6, 2, 1, 1]Output: [1, 5]Explanation: The repeating number is 1 and the missing number is 5.Constraints:$2 \le n \le 10^6$$1 \le arr[i] \le n$
